# JONA Support & Privacy

Public information pages for JONA by Ugurcan Yagiz. This repository contains only the website and support form, not the iPhone app source.

- Privacy Policy: https://ugurcanyagiz.github.io/jona-support/privacy.html
- Support: https://ugurcanyagiz.github.io/jona-support/support.html
- Support requests: https://github.com/ugurcanyagiz/jona-support/issues/new/choose

GitHub Pages publishes the root of `main` over HTTPS. The website has no added analytics, external fonts or client-side scripts.

Support issues are public. Do not post passwords, personal screenshots or unreviewed diagnostics.
